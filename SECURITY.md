# Reporting a security issue

Do not put credentials, exploit payloads against someone else’s site, or private build content in a public issue.

Use GitHub’s **Security → Report a vulnerability** option when available. If it is unavailable, contact the maintainer through [RobertDeVore.com](https://RobertDeVore.com/) to arrange private disclosure before sending sensitive details.

Include the affected version, a minimal local reproduction, the expected boundary and the observed result. Use synthetic data. Never test against a third-party site without authorization.

Website Cloner is a local, single-user application. Exposing its server publicly is unsupported. See the [security boundary](docs/security.md) for scope and limitations.
