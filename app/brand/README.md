# Kujo branding

The Kujo logomark was sourced from the owner's local kujolang.ai checkout (`assets/images/kujo-logomark.svg`) for this Kujo-branded tool on 2026-10-20. Brand reference: https://kujolang.ai/.

Departure Mono is bundled in `../fonts` with its SIL Open Font License and copyright attribution. Tabler icon licensing and pinned provenance are in `../icons`. All interface assets load locally.

Website Cloner’s homepage uses `home-agent-workflow.webp` from https://kujolang.ai/assets/images/home-agent-workflow.webp (retrieved 2026-10-22), at the owner's request. `../hero-dither.js` adapts the hero-only ordered-dither effect from https://kujolang.ai/assets/js/site.js. Both are bundled locally; animation pauses offscreen/in background tabs and respects reduced motion. The white wash keeps the form and headline readable.
